## 待提交 — 邮箱验证注册、卖家账号与订单归属

建议提交标题：`feat: add verified seller accounts and account-owned orders`

**解决问题：** 卖家此前靠私有链接访问订单，换浏览器或丢失链接后缺少统一找回入口。现在所有新订单必须先登录，自动保存到卖家账号，提供“我的订单”。

**主要修改：**

- 注册先校验6位邮箱验证码；新密码8–12位，英文字母/数字/英文特殊符号至少两类，不含空格。验证码使用带密钥摘要，10分钟有效、60秒重发间隔、5次错误上限；发送及注册以邮箱事务锁处理并发，发送失败不覆盖旧码，成功注册后一次性消费。
- QQ SMTP 发信通过本机私有配置读取授权码，采用465端口SSL/TLS与certifi信任链校验；新增`0010_registration_email`，新增`.env.example`及邮箱配置指南。
- 新增注册、登录、会话、退出及分页订单列表 API；邮箱统一规范化，密码使用 Argon2 摘要，账号会话与负责人会话分开，写请求校验 CSRF 和来源，登录限制尝试频率。校验错误不回传密码等原始输入。
- 新增 `seller_accounts`、订单归属与账号会话字段，以及 Alembic `0009_seller_accounts`。公开建单接口不接受调用方指定归属；摘要、聊天、补资料、附件、交付和发布操作统一验证账号。其他卖家即使拿到完整私有链接也不能访问。
- 新增 `/seller/register`、`/seller/login`、`/seller/orders`；首页及订单页提供账号入口，未登录建单显示登录提示，创建成功后可直接返回订单列表。账号登录后打开订单不再依赖链接令牌。
- 保留负责人独立审核流程，更新 OpenAPI、前端类型、浏览器测试、真实模型烟测及公网烟测脚本，使用指南与架构说明同步调整。
- 按用户要求不做旧单认领：本机开发库清除10份旧订单及15个文件，临时演示库清除4份旧订单及4个文件，同时清理对应检查点和过期验收状态。保留配置、密钥及负责人账号。此为此次本机操作，迁移代码不会自动清空其他机器的数据。

**验证：** 后端 PostgreSQL 完整测试156项通过；CI同环境离线测试70项通过、86项数据库测试跳过。账号覆盖登录持久化、密码摘要、退出撤销、过期、重复邮箱、CSRF、订单归属和跨账号访问。浏览器完整验收12组通过，覆盖注册建单、退出后跨浏览器登录找回、他人完整链接拒绝、图片上传删除、聊天、负责人审核交付返修和模拟发布；前端 lint/typecheck、Python Ruff、隔离生产构建已通过。自动测试未调用真实 MiMo，也未发送真实邮件；另通过本机实际 QQ SMTP 发信验收，注册验证码请求返回200、服务端接受邮件，未据此声称已确认收件箱到达。

**运行影响：** 首次升级先执行 `uv sync --project apps/server --locked --group dev` 安装锁定依赖，再执行 `uv run --project apps/server company-db-init`，再重启 API 和 worker；前端开发服务自动加载代码，生产服务需重新构建。当前本机已完成两个库的迁移，API 与 worker 已重启。

**边界：** 当前提供本机演示所需的邮箱密码账号，注册必须验证邮箱，尚无忘记密码流程；会话默认7天，到期后重新登录。开发与临时公网演示是独立数据库，分别注册，账号和订单不互通。原有真实MiMo、模拟Amazon及研究采集边界保持一致。
